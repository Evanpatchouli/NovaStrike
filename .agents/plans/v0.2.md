# NovaStrike v0.2 开发任务

## 项目背景

NovaStrike 是一个基于 Counter-Strike 2 Game State Integration (GSI) 的桌面辅助工具。

当前项目已经完成：

* Monorepo
* Electron Desktop
* React Overlay
* Fastify Backend
* WebSocket Gateway

目前：

* Electron 可以正常启动
* Overlay 可以正常显示
* Backend 正常监听
* WebSocket 正常工作

禁止：

* 修改 Monorepo 结构
* 引入新的状态管理方案
* 替换 Electron
* 替换 Fastify
* 替换 React
* 大规模重构已有代码

仅允许增量开发。

---

# 开发目标

实现：

Smoke Tracking MVP

即：

玩家投出烟雾弹

↓

系统识别烟雾弹出现

↓

创建烟雾计时器

↓

实时推送剩余时间

↓

Overlay 实时显示

↓

烟雾结束后自动移除

---

# 技术要求

## Backend

新增：

SmokeTrackerService

职责：

* 管理所有烟雾
* 创建烟雾
* 更新烟雾
* 删除烟雾
* 查询烟雾

建议结构：

apps/backend/src/modules/smoke

包含：

* smoke-tracker.service.ts
* smoke.types.ts

---

## Smoke 实体

定义：

```ts
export interface Smoke {
  id: string;

  type: "smoke";

  startedAt: number;

  expiresAt: number;

  remainingMs: number;
}
```

---

## 生命周期

烟雾创建：

18秒寿命

```ts
expiresAt = startedAt + 18000;
```

---

## Tick 更新

每100ms更新一次

自动计算：

```ts
remainingMs
```

---

## 自动销毁

当：

```ts
remainingMs <= 0
```

自动移除。

---

# WebSocket
